# 📸 Pixel Perfect Photography

A modern and responsive photography portfolio website designed for showcasing work and handling client bookings easily.

---

## ✨ Features

- 🎯 Professional Hero Section
- 🖼️ Responsive Image Gallery
- 📖 About Us Section
- 📞 Contact Section with details
- 💬 WhatsApp Booking Integration
- 📱 Mobile-friendly design
- 🎨 Clean and modern UI

---

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript

---

## 📂 Sections Included

- Home (Hero Section)
- Gallery
- About Us
- Contact Us
- WhatsApp Booking Popup

---

## 📱 Booking Feature

Users can:
- Click on "Book Now"
- Select event type (Wedding, Birthday, etc.)
- Automatically open WhatsApp with pre-filled message

---

## 🎯 Purpose

This project is designed for:
- Photography studios
- Freelance photographers
- Portfolio showcase
- Client booking system
